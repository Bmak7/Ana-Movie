# 📖 Ana Stream

**Ana Stream** is an Android (Phone & Android TV) app for **media streaming and downloading**, designed for Arabic users.  
It provides a clean and simple interface to access multiple sources for movies, anime, and TV shows.

---

## ✨ Features
- Stream and download from multiple community sources  
- Supports Android phones and Android TV  
- Multiple language sources (Arabic, Anime, Drama, International)  
- Simple and intuitive UI
